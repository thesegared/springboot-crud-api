# CRUD Personas - Spring Boot + Angular

Proyecto fullstack que permite gestionar personas mediante una API REST.

## Tecnologías

Backend
- Spring Boot
- JPA
- MySQL

Frontend
- Angular
- Bootstrap

## Funcionalidades

✔ Listar personas  
✔ Crear personas  
✔ Eliminar personas  

## Ejecutar proyecto


# Backend: Spring Boot
cd backend

mvn spring-boot:run

# Frontend: Para Angular
cd frontend

npm install

ng serve
